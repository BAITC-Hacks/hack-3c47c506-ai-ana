# Проверка и демонстрация: этап 7

Дата: 23.09.2026. Пользователь разрешил этап ответом «давай». Подготовка и один итоговый прогон завершены. Повторных прогонов не потребовалось.

## Объём и методика

- Общий серверный набор проверяет импорт исходного CSV, JSONL, валидацию, фильтры, объяснения и воспроизводимость.
- Браузерные сценарии проходят через собранный React-интерфейс, Vite preview и настоящий FastAPI с исходными 66 профилями. Ошибки сервера, сети и задержки моделируются только в явно обозначенных тестовых сценариях.
- Метрики записываются часами самого браузера: от события отправки формы до готовой выдачи и двух кадров отрисовки. Ввод полей, запуск процессов и начальная загрузка приложения не входят в этот интервал. Это время интерактивного подбора, а не время команды Playwright.
- Первый запрос после загрузки страницы записывается отдельно. Для основного запроса далее выполняются пять повторов. Сохраняются исходные измерения и статистика; пять наблюдений недостаточны для обещаний о производственной задержке или нагрузочной устойчивости.
- Проверка выполняется последовательно, с одним worker, без параллельного серверного тестирования во время замеров.

Команды из корня проекта (установленные зависимости описаны в README):

```bash
cd backend
.venv/bin/python -m pytest -q
cd ../frontend
npm run test:stage7
```

Вторая команда сначала собирает сайт и затем запускает отдельные FastAPI на 8002 и Vite preview на 4174. Процессы останавливаются после тестов. Переменные каталога заданы в конфигурации тестов явно; локальный пользовательский сервер не используется.

## Визуальный контроль

Новые снимки имеют префикс `stage7-`, прежние `stage6-` и `prototype-` не перезаписываются. Среда фиксируется: Chromium, Manrope из локальных файлов, светлая схема, начальный синий #2563EB, locale en-US как на прежних снимках, timezone Asia/Almaty. Нативное поле даты может показывать месяц первым; API получает календарное значение YYYY-MM-DD без часового пояса.

Снимки прототипа содержат вымышленные данные, поэтому с ними сравнивается композиция: шапка, сетка, типографика, палитра и отступы. Снимки этапа 6 содержат те же исходные карточки и раскрытые основания; они позволяют сравнить одинаковое содержание на 1440/768/390/320 px. После прогона проверены SHA-256 файлов: все четыре пары PNG этапов 6 и 7 совпали побайтно. Это относится только к этим фиксированным сценариям, а не ко всему приложению; [отчёт сравнения](stage7-visual-report.json). Для прототипа с другим содержимым остаётся ручная оценка композиции.

## Границы проверки

Локальный Linux и Chromium, без сетевого замедления и внешних AI-вызовов. Не проверяются публичный хостинг, WAN-задержки, одновременная нагрузка, Firefox/WebKit и физические телефоны. NVIDIA не реализован и не требуется для основной функции. Цена остаётся начальной; доступность подтверждена только календарём набора. Это проверка хакатонного каталога, не оценка коммерческого качества подрядчиков.
