## Что передаётся

Работающий React/TypeScript-сайт и FastAPI-сервер, загрузчик CSV/JSONL, до трёх рекомендаций с основаниями, диагностика и настройки оформления. Все 66 профилей предоставленного CSV используются без смешивания с фикстурами. Локальный адрес обычного запуска: http://localhost:5173; API — http://localhost:8000.

| Происхождение и дополненные поля | Метки профилей, отдельные original/team/demo, не влияют на порядок |

## Повтор запуска по README

Проверка выполнена один раз в отдельной временной копии без переноса прежних `.venv`, `node_modules` и `dist`.

| Шаг | Фактический результат |
|---|---|
| Новый venv и pip install -r backend/requirements.txt | Все закреплённые зависимости установлены, использован кэш pip |
| npm ci --offline --no-audit --no-fund | 59 пакетов из кэша в новый node_modules, успешно |
| npm run build | TypeScript и Vite успешно, Vite 682 мс |
| Новый FastAPI, GET /health | ready, 66 профилей, ожидаемая версия каталога |
| Vite dev и preview | Запустились, справочники получены через /api proxy |
| Отправка формы в Chromium, оба режима | MATCHED; HK-88430, HK-44923, HK-35215, 3 из 6 подходящих |
| Бренд и браузер | Логотип загружен, favicon HTTP 200; ошибок JavaScript нет |
| Локальные ссылки README и docs/*.md | Проверено 91 назначение в 10 Markdown-файлах, отсутствующих целей нет |

Использованы порты 8003/5175/4175 и явный API_PROXY_TARGET, чтобы сохранить пользовательские процессы на 8000/5173. Это документированный способ смены адреса; логика и данные приложения одинаковы. Chromium уже был установлен на машине, повторно не скачивался. Кэши пакетов использовались, поэтому это не проверка загрузки всех зависимостей из пустого кэша или установки на произвольной ОС.

## Измерения и ограничения

Этап 7: пять локальных production-повторов от отправки формы до готовой выдачи дали среднее 49.84 мс, медиану 48.8 мс и максимум 52.7 мс. Linux, Chromium, 66 профилей, один worker, без параллельной нагрузки. Ввод полей и начальная загрузка приложения не входят в измерение.

NVIDIA предусмотрен в документации как дополнительный провайдер, **не реализован и не проверен на API**. Зарезервированные переменные не читаются приложением. Нет бронирования, оплаты, аккаунтов, автоматических советов по ослаблению условий или доказанной масштабируемости. Для основного локального сценария дополнительных данных и доступов не требуется.
