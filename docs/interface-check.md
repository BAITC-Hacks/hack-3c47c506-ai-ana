## Повтор проверки

Из `frontend/`, после установки зависимостей и Chromium:

```bash
npm run test:stage7
```

В текущей виртуальной машине из-за нехватки памяти использовалась временная конфигурация на основе `playwright.config.ts`: один worker, Chromium с `--disable-gpu`, без записи trace, таймаут сценария 90 секунд и ожидания утверждений 20 секунд. Условия и проверки результатов не ослаблялись. После завершения дублирующего dev-сервера оставшиеся сценарии прошли без задержек запуска браузера.

Серверный код в этом изменении не менялся. Эти проверки не подтверждают работу публичного хостинга, физического мобильного устройства или нагрузочную устойчивость.
