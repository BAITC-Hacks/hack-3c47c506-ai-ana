## Изменения

В прежнем варианте у Рамь и Поньо совпадали объяснения для запроса «Алматы / Национальный ансамбль / свадьба / 24.09.2026 / 500 000 ₸». Четыре бедных описания пересмотрены: добавлены точные фрагменты об авторском проекте, казахском репертуаре, составе коллектива и заявленном выступлении. Уточнены похожие фрагменты лайв-бэндов и площадок. Маркетинговые рейтинги не используются. Источник заявления явно обозначен; недостаток конкретики и отсутствие независимого подтверждения отмечаются предупреждениями.

Все 66 профилей рассмотрены: 65 имеют цитаты, один (HK-25279) содержит только рекламное описание. Для него объяснение использует языки, форматы, длительность и цену. Если произвольный новый каталог не содержит подтверждённых отличий, приложение сообщает об этом; имена, ID, перестановка слов и удаление подходящих кандидатов не используются для искусственной уникальности.

Второе предложение объяснения теперь сопоставляет также указанные пользователем язык и часы. Null-длительность явно исключает фильтр часов. Версия правил объяснения повышена до `evidence-v2`, версия каталога и алгоритма отбора не меняются. Исходные CSV/HTML и производный каталог не редактируются.

README содержит назначение, возможности, сценарий пользователя, технологии, архитектуру, команды установки, воспроизводимые примеры для жюри, данные/интеграции, ограничения и статус публичного размещения. Существующие аккаунты, Docker Compose и автоматические фильтры сохранены; для подбора вход в аккаунт не нужен.

## Итоговый прогон

После завершения реализации выполнен один последовательный прогон: серверные проверки → сборка → Chromium с настоящим FastAPI и исходным CSV. Повторных прогонов не потребовалось, ошибок нет.

| Проверка | Результат |
|---|---|
| pytest, включая импорт, отбор, объяснения, API, детерминизм и аккаунты | **270 passed**, 10.80 с |
| TypeScript + Vite production build | Успешно, Vite 764 мс |
| Playwright / Chromium, весь текущий набор | **39 passed**, около 1.1 мин |
| Семь контрольных сценариев | Все ожидаемые исходы, количества и ID совпали |

| Ансамбли с одинаковыми ценой, языком и часами | Три разных объяснения без опоры на имена/ID, повтор идентичен |
| Все потенциально совместимые пары из 66 профилей | Различимы исходные основания без имён/ID; учитывается наличие общей свободной даты в 100-дневном календаре |
| Длина объяснений для всех 66 профилей | 1–2 предложения; цитаты принадлежат исходным описаниям |

Осталось прежнее предупреждение Starlette о будущем изменении TestClient/httpx; сборка и проверки не завершались ошибками. В браузерных демонстрационных сценариях и новой проверке ансамблей ошибок JavaScript нет. Пользовательская SQLite-база не использовалась: серверный прогон получил отдельный AUTH_DB_PATH в /tmp, браузерный — автоматически созданный временный каталог.

Проверка пар использует для каждой пары город, пересечение категорий/форматов и общих свободных дат, затем строит карточки на одной из таких дат. Отличительный фрагмент не зависит от запроса; бюджет, язык и часы могут только исключить кандидата. Поэтому не нужны миллионы одинаковых комбинаций. Проверка текстовая, а содержательность дополнительно проверена чтением; это не оценка коммерческого качества подрядчика.

Из корня проекта:

```bash
cd backend
.venv/bin/python -m pytest -q
cd ../frontend
npm run test:requirements
```

Вторая команда собирает frontend и запускает отдельные FastAPI и Vite preview на портах 8002 и 4174. Пользовательские процессы и база аккаунтов не используются для браузерных проверок. [Отчёт замеров](requirements-browser-report.json) содержит исходные наблюдения, версии, среду и методику; новые снимки имеют префикс `requirements-`. Старые снимки и отчёты этапов 7/8 сохранены.

Семь сценариев: **46.1–50.8 мс** от ручной отправки до готовой выдачи. Пять повторов основного запроса: среднее **59.4 мс**, медиана **53.9 мс**, максимум **82.2 мс**. ## Границы выводов

Проверка относится к исходным 66 профилям и календарю 23.09.2026–31.12.2026. Сравнение текстов подтверждает отсутствие одинаковых объяснений, а качество выбранных оснований дополнительно оценивается чтением. Истинность заявлений подрядчиков за пределами набора не установлена. Для произвольных новых одинаковых профилей различимость обещать нельзя.

Локальная проверка в Chromium не подтверждает скорость публичного сервера или устойчивость под нагрузкой. Загрузка страницы и ввод формы не входят в замер ручной отправки; автоматическое применение фильтров добавляет 400 мс ожидания после ввода. Публичная версия не развёрнута. Сам показ жюри остаётся действием команды; сохранённые снимки не заменяют живую демонстрацию.
