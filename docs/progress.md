## Этап 6: выполнено

Форма подключена к POST /api/recommendations, справочники и календарное окно загружаются из метаданных сервера. Категории остаются доступны по всему каталогу. Начальное состояние без карточек, загрузка, 1–3 результата, отсутствие категории, отсутствие подходящих, ошибка валидации и техническая ошибка показываются отдельно. Кнопки примеров отправляют реальные запросы; вымышленные карточки и переключатели состояний удалены.

Карточки показывают объяснения, evidence.text, пометки происхождения, синтетичности, дополненных города/цены и предупреждения из API. JSON и необработанные цитаты не выводятся вместо пользовательского текста. Браузер не пересчитывает фильтрацию или порядок. При смене даты сохранены остальные поля; исчезнувшие карточки объясняются по exclusions/eligible_ids. Сравнение выполняется только при неизменных остальных условиях и версиях каталога/алгоритма; отдельно обработан переход из пустой выдачи.

Новый запрос сразу убирает старые карточки, отменяет предыдущий запрос и игнорирует запоздалый ответ по номеру запроса. При редактировании без отправки прежняя выдача явно подписана. Ошибки HTTP 422 привязываются к полям, ошибки сети, каталога и неверного формата ответа дают отдельное состояние с повтором. Таймаут — 12 секунд. Успешные ответы проверяются по структуре через Zod без преобразования или сортировки данных.

Оформление выделено в отдельный компонент: смена цвета сохраняет форму/карточки/раскрытые основания и не отправляет запросы. Исправлена контрастность hover/pressed для произвольного акцента, добавлен возврат фокуса после закрытия настроек. Повреждённое/недоступное хранилище не мешает работе. Исходный логотип сохранён. Vite dev/preview проксируют /api к серверу; README обновлён.
