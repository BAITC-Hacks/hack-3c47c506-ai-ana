# Проверка материалов хакатона

Проверены три предоставленных файла: CSV с профилями, HTML-превью и четырёхстраничное PDF-задание. Исходные файлы не изменялись. Приложение в рамках этой проверки не создавалось: ниже приведены результаты аудита данных и вычисленные ожидаемые ответы для будущей реализации.

## Как использовать файлы

| Материал | Роль в проекте |
|---|---|
| `hackathon dataset anonymized .csv` | Основной источник всех профилей, полных описаний и календарей |
| `hackathon dataset preview.html` | Справочное представление карточек; не источник полного календаря и не утверждённый дизайн приложения |
| `HackAlem AI_ Хакатон-задача_ умный подбор подрядчиков.pdf` | Требования организаторов, условия живой проверки и оценка |

Отдельного JSONL среди приложений нет, но для начала работы он не требуется. Правильное решение — загрузить CSV в единую внутреннюю модель и при необходимости воспроизводимо экспортировать JSONL. Нельзя включать вымышленный демокаталог только потому, что отсутствует файл с расширением `.jsonl`.

Дубликатов строк, id и имён не обнаружено. При проверке структуры, чисел, флагов и календарей ошибок не найдено. Это не означает независимого подтверждения рекламных заявлений из описаний.

Цены заданы целыми тенге, от 100 000 до 6 000 000. Числовые лимиты присутствия — от 2 до 12 часов. Девять `null` относятся к трём флористам, трём декораторам и трём поставщикам подарков. Календари содержат валидные неповторяющиеся даты внутри окна 23.09.2026–31.12.2026.

Особенности импорта:

- UTF-8 без BOM; разделитель столбцов — запятая, кавычки полей — двойные; строки CRLF.
- Списки в `categories`, `event_formats`, `languages`, `busy_dates` разделены знаком `|`.
- Булевы значения записаны как `True` и `False`; нужна явная конвертация. Выражение `bool("False")` даёт неверный для этих данных результат.
- Пустая ячейка `max_hours` в существующем столбце преобразуется в `null`. Отсутствующий столбец — ошибка схемы.
- Описания содержат запятые и кавычки; простое разбиение строки по запятой не подходит.

## Чем HTML отличается от CSV

В HTML 66 карточек с совпадающими id, именами и категориями. Счётчики занятых дней за всё окно и за декабрь совпадают с CSV.

У 39 карточек описания обрезаны с многоточием. Ещё 11 описаний отличаются только пробелами и переносами; остальные 16 совпадают. Необъяснённых расхождений среди проверенных полей не найдено.

В HTML нет списка занятых дат каждого подрядчика: показаны только итоговые количества. Восстановить по ним доступность на определённый день невозможно. Для рекомендаций и объяснений нужно использовать CSV.

В HTML нет изображений и SVG-логотипа. Постоянная иконка проекта в переданных материалах отсутствует. Его оформление не заменяет выбранный пользователем светлый дизайн А.

| `HK-60927`, `HK-90006` | Минимальный заказ 15 и 20 изделий | Не придумывать цену за штуку и не обещать меньший заказ |

| `HK-31819` | Есть казахская музыка в репертуаре, но в языках обслуживания русский и английский | Репертуар не равен языку обслуживания |
| `HK-74147` | Имя профиля и название дуэта в тексте отличаются | Сохранить id и имя; не создавать дополнительные записи |

У `HK-10990`, `HK-23752`, `HK-31819` исходные описания содержат эмодзи. Оригинал нужно сохранять, а в видимом интерфейсе и объяснениях выбирать содержательные фрагменты без эмодзи. Очищенный текст нельзя выдавать за неизменённую дословную цитату.

Отзывы, заявления о превосходстве, рейтингах и полезности продукции не следует превращать в независимо подтверждённые преимущества. Для рекомендаций достаточно конкретных характеристик услуг и проверяемых условий.

## Готовые сценарии для будущей проверки

Все запросы ниже имеют формат «корпоратив». Язык не задан. Сортировка: цена по возрастанию, затем id. Подключён только исходный набор.

| Сценарий | Город, категория | Дата | Бюджет, ₸ | Длительность | Ожидаемый ответ |
|---|---|---|---:|---|---|
| Плотная категория | Алматы, Ведущий | 30.09.2026 | 1 000 000 | не задана | Из 10 профилей проходят 6; показаны `HK-88430`, `HK-44923`, `HK-35215` |
| Другая дата | Алматы, Ведущий | 01.10.2026 | 1 000 000 | не задана | Проходят 2: `HK-88430`, `HK-44923`; `HK-35215` занят |
| Редкая категория | Алматы, Декоратор | 23.09.2026 | 2 500 000 | 5 часов | Из 3 проходят 2: `HK-11484`, `HK-90004`; `HK-90003` занят |
| Условия не проходят | Алматы, Ведущий | 30.09.2026 | 100 000 | не задана | `NO_MATCHES`: основные причины — 1 занят, 1 не берёт формат, 8 превышают бюджет |
| Категории в городе нет | Астана, Декоратор | 23.09.2026 | 2 500 000 | не задана | `CATEGORY_UNAVAILABLE` |
| Свободная площадка | Астана, Отель | 23.09.2026 | 3 000 000 | 5 часов | Подходит `HK-90012`, начальная цена 2 800 000 |
| Занятая площадка | Астана, Отель | 25.09.2026 | 3 000 000 | 5 часов | `NO_MATCHES`: единственный отель занят |

Первый запрос возвращает Куррапику, Мицури Канроджи и Кики с начальными ценами 500 000, 650 000 и 900 000 ₸ соответственно. Повтор должен сохранить этот порядок.

Отель в Астане в данных есть. Прежний вымышленный пример «в Астане нет отелей» не подходит для живой демонстрации. В качестве отсутствующей категории проверена комбинация «Астана + Декоратор».

Эти результаты вычислены по данным отдельно от будущего приложения. После реализации нужно повторить их через API и интерфейс: аудит CSV не заменяет интеграционные тесты.

## NVIDIA API

Пользователь сообщил о наличии API. Ключ, конкретная модель и доступная квота не проверялись, внешние модельные вызовы не выполнялись.

В полном промпте предусмотрен отдельный дополнительный этап: извлечение отличительных фактов из описаний с точными цитатами, проверка результата и сохранение кэша. Фильтрация и порядок карточек остаются программными, основной подбор работает без NVIDIA.

Официальный hosted API предоставляет Chat Completions по адресу `https://integrate.api.nvidia.com/v1/chat/completions`. Конкретную доступную модель нужно проверить в аккаунте; наличие в каталоге само по себе не подтверждает доступ пользователя. Источник: [NVIDIA LLM APIs](https://docs.api.nvidia.com/nim/reference/llm-apis).

Настройка ключа выполняется только на сервере. Вызовы разрешаются в рамках отдельно согласованного этапа. Разработку приложения и подключение API эта проверка файлов не начинала.
